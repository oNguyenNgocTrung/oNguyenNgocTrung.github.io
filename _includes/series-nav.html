{%- comment -%} Previous/next navigation within a series. A post joins a series with `series: ` in its front matter; the parts are every post sharing that slug, in date order. Nothing lists them by hand, so inserting a part means giving it a date between its neighbours. Reached through the theme's `after-content` hook, which _config.yml sets as a default on every post. Renders nothing for a post without `series`. {%- endcomment -%} {%- if page.series -%} {%- assign parts = site.posts | where: "series", page.series | sort: "date" -%} {%- for part in parts -%} {%- if part.url == page.url -%} {%- assign position = forloop.index -%} {%- assign prev_index = forloop.index0 | minus: 1 -%} {%- assign next_index = forloop.index0 | plus: 1 -%} {%- endif -%} {%- endfor -%}
Part {{ position }} of {{ parts.size }} in the series {{ page.series | replace: "-", " " }}
    {%- for part in parts -%} {%- if part.url == page.url -%} {{ part.title | strip_html }} {%- else -%} {{ part.title | strip_html }} {%- endif -%} {%- endfor -%}
{%- if prev_index >= 0 -%} ← {{ parts[prev_index].title | strip_html }} {%- endif -%} {%- if next_index < parts.size -%} {{ parts[next_index].title | strip_html }} → {%- endif -%}
{%- endif -%}
